Clinical safety: No breakpoint database is bundled. Confirm the organism, antimicrobial, infection site, dosing/route, table edition, footnotes, and applicable ATU in the official EUCAST tables. This tool is not a substitute for a validated laboratory AST system.

Sample and breakpoint data

Accepts exact, <, <=, >, >= values.

Optional Area of Technical Uncertainty (ATU)

If the MIC interval overlaps the entered ATU range, classification is withheld for manual review.

Interpretation

Enter a reported MIC and verified S/R cutoffs to obtain a category.

Category definitions

  • S — Susceptible, standard dosing regimen.
  • I — Susceptible, increased exposure (not resistant).
  • R — Resistant.
  • ATU — Supplied technical uncertainty interval; review manually.
  • UNDETERMINED — Reported MIC range spans categories.
Entire interpretation runs in this browser; form data are not submitted to a server. Only data entered in this session are used. No automatic breakpoint updates or clinical validation are provided. EUCAST S/I/R definitions.
